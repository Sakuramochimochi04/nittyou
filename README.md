# みんなの日程調整

ダンスサークルのユニット練習向けの日程調整サイトです。オーナーが候補日と時間帯を決め、メンバーは日付ごとに ◎ △ × で行ける時間を塗ります。結果は「全員◎の時間」「時間ごとの重なり」「メンバー別の一覧」で確認できます。

**中身は暗号化して保存します。** 調整の内容（タイトル・日付・名前・回答・メモ）はブラウザの中で暗号化されてから Supabase に保存されます。鍵は共有リンクの `#` より後ろにだけあり、サーバーには送られません。運営者（あなた）が Supabase の管理画面を見ても、読めない文字列しか見えません。

---

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体 |
| `style.css` | 見た目 |
| `app.js` | 動き（暗号化・入力・集計・いつもの予定） |
| `config.js` | **Supabase の接続先を書くファイル（ここだけ編集）** |
| `supabase/schema.sql` | Supabase に貼るデータベース設定 |

## まず手元で試す（お試しモード）

`config.js` が空のままだと「お試しモード」で動きます。データはそのブラウザの中にだけ保存されます。

パソコンでこのフォルダを開き、次を実行してから `http://localhost:8000` を開いてください。

```
python3 -m http.server 8000
```

（`index.html` をダブルクリックで開いても、たいていは動きます。）

## 本番の準備

### 1. Supabase を用意する

1. https://supabase.com でアカウントを作り、「New project」でプロジェクトを作ります。リージョンは「Northeast Asia (Tokyo)」がおすすめです。
2. 左メニューの **SQL Editor** を開き、`supabase/schema.sql` の中身を全部貼り付けて **Run** を押します。「Success」と出ればOKです。
3. 左メニューの **Project Settings → API Keys**（または **API**）を開き、次の2つを控えます。
   - **Project URL**（`https://xxxx.supabase.co`）
   - 公開用のキー（**publishable key** `sb_publishable_…`、または **anon public** キー `eyJ…`）

   ⚠️ **service_role / secret キーは絶対に使わないでください。** ページに書いたキーは誰でも見られます。公開用キーでも、SQLで許可した関数しか呼べないので安全です。

### 2. config.js に書き込む

```js
window.CHOSEI_CONFIG = {
  appName: 'みんなの日程調整',          // サイト名を変えたいときはここ
  supabaseUrl: 'https://xxxx.supabase.co',
  supabaseKey: 'sb_publishable_xxxx'
};
```

### 3. GitHub Pages で公開する

1. GitHub で新しいリポジトリを作ります（Public で大丈夫です。鍵やデータはリポジトリに入りません）。
2. このフォルダの中身（`index.html` `style.css` `app.js` `config.js` `supabase/`）をアップロードします。「Add file → Upload files」でドラッグ＆ドロップできます。
3. リポジトリの **Settings → Pages** を開きます。「Build and deployment」の Source を **Deploy from a branch**、Branch を **main / (root)** にして Save します。
4. 1〜2分待つと `https://ユーザー名.github.io/リポジトリ名/` で公開されます。

### 4. 動作確認

1. 公開したURLを開きます。黄色い「お試しモード」の帯が**出ていない**ことを確認します。
2. 調整を1つ作って、スマホから入力してみます。
3. Supabase の **Table Editor → events / answers** を開いて、中身が読めない文字列になっていることを確認できます。

## しくみ（知っておくと安心なこと）

- **共有リンクが鍵です。** なくすとオーナーも含めて誰も開けません。運営者も復元できません。作成直後の画面で、メモアプリなどに保存するよう案内しています。
- **パスワード**：オーナー用とメンバー用があります。ブラウザで「調整ID＋鍵＋パスワード」から確認用の値を作り、Supabase 側でさらに bcrypt でハッシュ化して保存します。元のパスワードは運営者にも見えません。
- **この端末に覚えておくもの**（ブラウザの localStorage）：開いた調整の一覧、「次から入力しない」にした自分の回答、いつもの予定（プリセット）、名前。別のスマホに移ると引き継がれません。
- **サークル同士は見えません。** 調整の一覧はその端末で開いたものだけです。他のサークルの調整は、リンクを知らない限り開けません。
- **いたずら対策**：オーナーはログインすると、メンバー別の一覧から回答を削除できます。1つの調整につき回答は300件までです。

## 今後の注意点

- **Supabase の無料プラン**には容量などの上限があり、しばらく使われないとプロジェクトが一時停止されることがあります。利用が増えたらプランを確認してください。
- 他のサークルにも公開する場合は、簡単な**利用規約・プライバシーポリシー**のページを置いておくと安心です。
- 誰でも調整を作れる設計なので、もし大量作成のいたずらがあれば、Supabase 側で作成数を制限する仕組みを追加できます。
